# Recipe Book

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue.svg)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Cooking Tool](https://img.shields.io/badge/cooking-tool-green.svg)]()

A recipe management CLI with meal planning and shopping lists.

## ✨ Features

- **Recipe Management** - Add, edit, delete recipes
- **Categorization** - Cuisine, meal type, difficulty
- **Search** - Find recipes by name, ingredient, tag
- **Meal Planner** - Weekly meal planning
- **Shopping List** - Generate shopping lists from recipes
- **Rich UI** - Beautiful colored terminal output

## 📦 Installation

```bash
git clone https://github.com/Master-626/recipe-book.git
cd recipe-book
pip install .
```

## 🚀 Quick Start

```bash
# Add a recipe
recipe-book add "Pasta Carbonara"

# List recipes
recipe-book list

# Search recipes
recipe-book search pasta
```
